# 分析口径说明

本文件固定应用内所有指标与分级的业务含义。代码实现见 `domain.py`、
`observability.py`、`analysis.py`、`decision.py`。

## 1. 三类独立观察

| 观察 | 数据来源 | 能回答 | 不能回答 |
| --- | --- | --- | --- |
| 功能是否出现 | `rendered_objects`（非孤儿） | 界面是否渲染过某类对象 | 用户是否注意到、是否理解 |
| 用户是否点击 | `interactions` 的 tap/dismiss/none | 用户对目标有无行为反应 | 点击是否出于正确理解（可能误触） |
| 能否正确解释 | `study_responses` 中 `review_state='coded'` 的人工编码 | 用户对系统意图的解释是否正确 | 不可外推到未应答人群 |

新闻报道只说明厂商发布了 Reality View，**没有公布对理解效果的独立验证**，
因此任何发布信息都不进入理解度证据。

## 2. 可观察程度分级（保守优先，宁降勿升）

| 级别 | 进入条件 | 可报告内容 |
| --- | --- | --- |
| L1-可判定 | 版本对齐 **且** `exposure_state='full'` **且** 有 coded 未撤回问卷 | 功能出现、点击行为、与当时显示/计划绑定的理解度 |
| L2-仅行为可观察 | 版本对齐，但曝光为 partial/late，或缺 coded 问卷 | 功能出现、点击行为；理解度不可证实 |
| L3-关联缺口 | 有记录但无法关联当时显示/计划（版本错配、无渲染对象） | 只能报告记录存在，不做理解解释 |
| L4-无证据 | 无任何可关联对象、交互或问卷 | 仅计数 |

硬约束：

- `late`（晚到曝光）即使后续补齐，事件时点可见性仍不可证实，最高 L2；
- `partial`（部分曝光）最高 L2；
- 撤回（withdrawn）问卷不参与任何判定；pending/revised 不计入理解率；
- 误触是行为质量标记，不单独改变会话分级。

## 3. 指标定义

- **理解率** = L1 会话中 `coded_intent='understood'` 的会话数 ÷ L1 且
  coded 的会话数。L2 的 coded 问卷不与当时显示绑定，不计入分子分母。
- **行为正确率** = 有明确 correct/incorrect 结果的会话中 correct 会话占比；
  `task_outcome='unknown'` 与 `action='none'` 不参与。
- **误触率** = 发生 tap/dismiss 的会话中，点击目标不属于本会话渲染
  对象集合的会话占比。
- **问卷覆盖率** = 有有效（未撤回）问卷的会话 ÷ 全部会话。问卷完成者
  不是曝光总体的随机样本，覆盖率只描述样本结构，理解率**禁止外推**。

## 4. 必须显式披露的缺口

分析报告第 4 节固定列出：无问卷会话数、待复核问卷数、版本错配会话数、
晚到/部分曝光会话数、孤儿对象数、隔离区行数、误触会话数。无问卷或
无法关联的范围不得在结论中被省略。

## 5. 决策门槛与建议动作

门槛集中在 `decision.DecisionThresholds`，CLI 可覆盖，默认值偏保守：

| 门槛 | 默认值 | 含义 |
| --- | --- | --- |
| `min_l1_sessions` | 8 | 每个显示版本最少 L1 会话，否则暂缓或补做 |
| `min_l1_per_task` | 2 | 每个任务类型最少 L1 会话，否则补做该任务 |
| `min_comprehension_rate` | 0.75 | 低于则暂缓开放 |
| `max_mis_tap_rate` | 0.15 | 高于则限制试用人群 |
| `min_questionnaire_coverage` | 0.60 | 低于则补做研究 |

动作只有三类，且每条建议都带证据回链（具体报告文件与字段）：

1. `hold_rollout` 暂缓开放：零 L1 证据，或理解率低于门槛；
2. `follow_up_study` 补做任务研究：证据量/覆盖不足或任务级缺口；
3. `restricted_trial` 限制试用：指标达标但仍需限量，仅向个人证据
   合格（足够 L1、理解率达标、无误触、授权有效）的驾驶员开放。

应用不会输出"全量开放"建议——合成/有限样本不足以支持该结论。

## 6. 数据质量处置

- 空字段、非法枚举行进入 `quarantine_rows`，不参与分析，报告计数披露；
- 找不到会话的渲染对象标记 `is_orphan=1` 并保留，不挂到任何会话；
- 点击目标与本会话渲染对象不匹配的 tap/dismiss 标记 `is_mis_tap=1`；
- 重复导入按主键幂等跳过，冲突写入 `import_conflicts`，**已导入的
  显示/意图版本永不被后续导入覆盖**。
